Spelling fixes as you type, in every Mac app.

Mac autocorrect only works in some apps. In Chrome, Arc, Slack, Obsidian and chat apps, typos just get a red line. Keymend fixes them as you type, using Apple's own spell checker. It never goes online.

What Keymend sees, and what it does with it

To fix typing, an app has to see your keys. That makes the rules below matter. Each one is enforced by macOS or checked by a test.

No internet, enforced by Apple

Keymend runs in Apple's App Sandbox with no network permission. macOS blocks any connection.

Nothing typed is saved

Only the word you are typing is held in memory, and it is cleared when the word ends. No logs, no analytics. The optional Learning Dictionary, off until you turn it on, keeps single words and counts, encrypted, on your Mac.

Password fields are off limits

Password fields turn on macOS Secure Input, which stops Keymend from seeing keys. A terminal password prompt only does this if the terminal turns it on, so read the exception.

Only two permissions

Input Monitoring to see keys, and permission to type the fix. No screen recording or contacts. Files only when you pick one to export or import learned words.

No third-party code

Plain Swift and Apple frameworks. No analytics, no auto-updater.

Open source

Read every line, or build it yourself. MIT license.

Install

  1. Download the .dmg from GitHub Releases and drag Keymend into Applications.
  2. Open Keymend. The setup window shows exactly where to click to allow Input Monitoring and typing.
  3. Type as usual. The K in your menu bar shows how many typos it fixed today.

Keymend is signed with a Developer ID and notarized by Apple, so it opens like any other app. Step-by-step guide with pictures.
